# 自選股變化狀態與下一步

Web 首頁的自選股列表按單行聚合展示每隻股票的當前處理狀態。該能力用於把分散在圖標、任務狀態和詳情入口裡的信息收斂成可掃描的三段信號。

## 展示結構

每隻自選股保留原有股票名、代碼、最新分析時間、評分標籤、刪除按鈕和點擊打開最新詳情能力，並新增三段緊湊信號：

| 信號 | 含義 | 當前來源 |
| --- | --- | --- |
| 變化 | 這隻股票相對今日分析目標的變化狀態 | `analyzedToday`、`latestItem`、今日狀態查詢結果 |
| 狀態 | 當前是否已完成、待更新、確認中或任務運行中 | `analyzedToday`、`activeTask`、今日狀態查詢結果 |
| 下一步 | 用戶下一步最應做什麼 | 最新詳情可用性、任務狀態、今日狀態 |

## 狀態映射

| 場景 | 變化 | 狀態 | 下一步 |
| --- | --- | --- | --- |
| 今日已分析且最新詳情可打開 | 今日已更新 | 已完成 | 打開最新報告 |
| 有歷史報告但今天未分析 | 有歷史報告 | 待更新 | 運行今日分析 |
| 沒有任何歷史報告 | 等待首次分析 | 待更新 | 運行今日分析 |
| 正在確認今日狀態 | 確認中 | 正在確認 | 等待狀態確認 |
| 今日狀態查詢失敗或未知 | 狀態未知 | 待刷新 | 刷新確認 |
| 存在運行中或等待中的任務 | 保留原變化狀態 | 任務狀態 | 等待任務完成 |

## 交互邊界

- 點擊自選股主體仍只負責打開最新報告詳情。
- 沒有詳情、詳情查詢中或詳情狀態未知時，繼續展示原有提示。
- 刪除按鈕保持獨立，不觸發打開詳情。
- 本次不新增單隻股票的立即分析按鈕，避免與現有批量分析入口產生重複提交語義。

## 後續擴展

- 接入實時漲跌幅後，`变化` 可從“是否有報告”升級為“價格變化 + 觀點變化”。
- 接入 ResearchArtifact 後，`状态` 可展示 thesis 是否被觸發或失效。
- 接入實體跳轉模型後，`下一步` 可升級為可執行動作，如打開研報工作臺、創建監控或加入組合。
